# Known limitations

- Local single-user lab tool, without login, role isolation, TLS termination or multi-user audit identity. Bind loopback. Remote hosting is not prepared or authorized here.
- Live adapters cover inspected PMLR volume layouts, RSS 2025 proceedings, NeurIPS 2024 main proceedings and the NeurIPS 2026 virtual-program paper listing. Conference discovery searches the official PMLR directory and supported starter links, not the entire web; older PMLR layouts may require updates and successful inventory checks do not guarantee accessible PDFs. The 2026 listing keeps main, datasets, position, journal and other published tracks separate; workshops outside that listing and other years/conferences need explicit adapters/imports. CSV/metadata imports do not establish a publisher's full inventory count by themselves.
- The 2024 smoke dataset is a ten-paper sample of an observed 4,034-paper main inventory. A separate full live 2026 inventory collected 9,139 listed papers. Only two PDFs were downloaded before repeated OpenReview HTTP 403s paused the job; inventory completeness and PDF completeness remain separate. Offline acceptance tests do not establish live source access.
- arXiv resolution is conservative; weak matches remain unresolved/reviewable. Optional web search needs a configured public JSON endpoint; no default provider, automatic Scholar lookup, Google scraping or invented URLs exists.
- Deterministic affiliation extraction covers limited explicit layouts and the first four bounded PDF pages. LAS enrichment is bounded, optional, evidence-validated and analyst-reviewed. It cannot guarantee complete affiliations. Nationality/residence are not inferred.
- Image-only PDFs require OCR, which is not implemented. PDF parsing is bounded to 500 pages/5,000,000 extracted characters. Access-controlled/paywalled documents are not bypassed.
- Canonical paper identity currently follows official source identity; unrelated URLs for the same publication may need future corroborated identity handling. Author identities never merge on names alone. Identity edges require explicit review and are reversible.
- SQLite and local files suit one workstation and modest collections. Search uses FTS but current filtering/count assembly includes Python-side work; large multi-conference benchmarks have not been run. Exports are synchronous with bounded disk-backed files, not queued background export jobs.
- ZIPs contain one preferred available PDF per paper; an oversized single PDF is reported rather than split. Exports have configured caps/TTL; keep original storage/backups for long-term provenance.
- Graceful worker shutdown waits for submitted network work; forced kills can leave leases until expiry. Rate limiting is per process, so use one normal worker unless carefully coordinating source traffic.
- Offline/browser checks use mocked network transports. Live LAS discovery/inference has not been verified in this preparation. macOS, the full CI version matrix, and Docker runtime are only verified if specifically recorded in the preparation report.
- Automated accessibility checks and a tested keyboard/responsive workflow are not a comprehensive manual accessibility audit.
- No public license has been selected. Copyright/redistribution of collected third-party documents is separate from the application's original code; runtime documents never belong in this repository.

The default link-first workflow now accepts any public conference URL for inspection, but generic parsing only recognizes explicit linked paper containers. JavaScript-only pages still need a connector or import. Explicit PDF-only jobs also query public OpenAlex OA copies without credentials; this is bounded indexed-source discovery, not universal internet coverage. Source/metadata failures, quota limits, ambiguous identities and landing-page-only records remain visible/unresolved. See [link-first collection](link-first-collection.md).

WACV 2026 now has a source-specific main-conference collector. Its public feed does not currently supply paper-PDF links; slides/poster assets are deliberately excluded. Actual paper downloads depend on conservative alternate-copy resolution and may remain missing or require review. Other WACV years and workshops remain unsupported unless imported separately. See [WACV 2026](wacv-2026.md).

The default analyst workflow now automatically saves titles and retrieves free PDFs after one Collect papers action. The default scope is still ten papers; full conference scope requires explicitly choosing Entire conference. Source identification/ambiguity and unavailable or uncertain copies can still require attention. Advanced manual title/PDF stages remain available, but are not required in the default workflow. See [automatic collection](automatic-collection.md).
